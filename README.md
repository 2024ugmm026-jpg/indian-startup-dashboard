# 🚀 Startup Dashboard

An interactive **Startup Analytics Dashboard** built with **Python, Pandas, Plotly, and Streamlit** to explore and analyze startup-related data through an easy-to-use web interface.

🔗 **Live Demo:** https://startup-dashboard-z7b7wbrklkkyhcjuzhenan.streamlit.app/

---

## 📌 Project Overview

The Startup Dashboard provides an interactive way to analyze startup data and extract meaningful insights.

Instead of manually analyzing large datasets, users can use the dashboard to filter data, explore different metrics, visualize trends, and understand startup-related patterns.

This project demonstrates practical skills in:

* Data Cleaning
* Exploratory Data Analysis (EDA)
* Data Visualization
* Interactive Dashboard Development
* Python Programming
* Streamlit Deployment

## ⚙️ Installation & Setup

### 1. Clone the repository

```bash
git clone https://github.com/your-username/startup-dashboard.git
```

### 2. Navigate to the project directory

```bash
cd startup-dashboard
```

### 3. Install the required libraries

```bash
pip install -r requirements.txt
```

### 4. Run the Streamlit application

```bash
streamlit run app.py
```

The application will open in your browser.
